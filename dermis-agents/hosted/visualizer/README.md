# Visualizer Agent

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Analyzes Dermis tactile-sensor recordings (magnetic touch pods + IMU at 350 Hz) for **charts of Dermis recordings: time series, overlays, histograms, scatter plots, pies, radar profiles, heatmaps and dashboards**.

Focus: the right chart for the question, the numbers behind every chart.

Reads recordings from SpacetimeDB (local dataset fallback), computes contact force, slip vibration, sensor saturation and noise, judges them against this application's limits, charts the result and recommends what to change.

Keywords: chart, charts, plot, graph, visualize, visualise, visualization, histogram, scatter, pie, donut, radar, heatmap, overlay, dashboard, draw, show me, compare, versus, trace, over time

Example questions:
- Dashboard
- Plot episode 4
- Compare episode 4 with SafeGrip on
- Histogram of peak force
- Scatter latency vs mass
- Heatmap of success
- Radar of episode 40
