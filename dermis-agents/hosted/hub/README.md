# Dermis Hub: Robot Touch Intelligence

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

The front door to Dermis touch intelligence. Routes questions about robot touch sensing to 13 specialist agents (humanoid arms, industrial manipulators, quadrupeds, prosthetics, surgical, warehouse, food & agriculture, care robots, teleoperation, sensor health, robot-learning data), plus a Data Explorer for pandas-style tables and a Visualizer for charts (time series, overlays, histograms, scatter, pie, radar, heatmaps), and combines their answers. Can compare one recording across every application at once.

Example questions:
- Analyze episode 4
- Compare all applications on episode 4
- Show me a dashboard chart
- Which items do we drop most in the warehouse?
- Are any sensor readings unreliable?
- What data should we collect next?
